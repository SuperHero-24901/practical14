# Student Registration Portal

## Aim
Student Registration Portal — a React practical built with Vite, React, React Router DOM where relevant, and Tailwind CSS v4.

## Concepts used
- React functional components and JSX
- Component-based UI and responsive utility-first styling
- React hooks
- Form state, validation, and interactive feedback where relevant

## Requirements
- Node.js 20.19+ or 22.12+ recommended
- npm

## Run the project
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

Each practical is independent. Open its folder in VS Code and run the commands from that folder.


## Controlled components
Each input's `value` comes from React state, and its `onChange` handler updates that state. The live preview reads the same state, so the UI always reflects the current form values.
